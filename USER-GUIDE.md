# User Guide (version 1)

This guide is for the old version 1 site. For the current site, visit
[estenlab.com](https://estenlab.com).

Visit <https://company.cyberlibrary.workers.dev>.

- Choose **Research** to browse report categories or search the library.
- Open a report to read its summary and view the sample PDF in the browser.
- Choose **News** to browse cybersecurity headlines and follow the publisher's source link.
- Use **About** for a brief description of the library.
