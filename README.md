# EstenLab: Version 1

This is the documentation for **version 1 of EstenLab**. Back then it was
called the Tess & Co Cybersecurity Research Library.

**The current site is [estenlab.com](https://estenlab.com)** (version 2).

The old version 1 site is still online at
<https://company.cyberlibrary.workers.dev>.

## What version 1 did

Visitors could browse cybersecurity research by topic, search for reports,
read PDFs in the browser and see cybersecurity news.

- [User Guide](USER-GUIDE.md): how to use version 1
- [Changelog](CHANGELOG.md): what each version added

## What is new in version 2

- A new name: **EstenLab**, at its own address, estenlab.com
- **Games** that teach safe habits, like spotting scam messages
- **Security Lab:** free tests of your own online safety
- **News** collected by itself from trusted news sites, all day
- An **admin page** to upload new reports
- Faster pages and stronger security
