# Version 1 notes

Version 1 provides a responsive cybersecurity research library and curated news section.

- Browse populated Research categories and search/filter reports.
- Open six sample PDF documents in the browser.
- View publisher-attributed cybersecurity headlines, with a bundled snapshot fallback.
- Use a mobile navigation menu that dismisses on outside taps and keyboard Escape.
- Use native browser history; the site has no custom Back controls or document breadcrumb trail.
- Use text-only “Other areas of expertise” content on About; matching category photos appear on populated Research cards.
- Apply restrictive content/security headers and same-origin API handling.

The public service address is <https://company.cyberlibrary.workers.dev>. This document records scope, not a claim that the system has been independently certified or audited.
